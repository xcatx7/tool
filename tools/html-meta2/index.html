💡 專業建議：您的 Meta 還能補充哪些重要欄位？

1. og:image:width & height

填入 1200 與 630。能提示 FB / LINE 提前配置版面尺寸，大幅避免第一次分享時圖片縮圖出不來的問題。

2. twitter:image

配合 summary_large_image，Twitter / X 或部分現代社群預覽會優先抓取此項。

3. og:image:alt

分享圖的替代文字。加強 SEO 無障礙友好度與搜尋權重。

4. og:site_name

網站所屬品牌名稱，避免搜尋引擎將頁面標題與品牌混淆。

5. robots

設定 index, follow 明確告訴 Google 爬蟲安心收錄並索引子連結。

6. author / 版權標籤

標示建商或代理品牌名稱，強化 Google Knowledge Graph 知識圖譜關聯度。
